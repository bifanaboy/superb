# PR Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the four-item finish menu the gate before any pull request, with "Ship it" as the wave-through that runs commit, push, PR, merge, and cleanup without another prompt.

**Architecture:** A Node contract test pins the skill text. Then the finishing skill gains a gate rule and a corrected menu and Quick Reference, and the two implementation flows gain one line each forbidding a direct PR. No plugin code changes.

**Tech Stack:** Markdown skills, Node 20 ESM test script, Bash wrapper.

**Spec:** `docs/superpowers/specs/2026-10-31-pr-gate-design.md`

## Global Constraints

- The menu has exactly four options, in this order: Ship it, Merge back locally, Push and create a Pull Request, Keep the branch as-is.
- The string `(default)` appears nowhere in the finishing skill.
- Gate rule text: `Do not push, open a pull request, or merge before this menu` and `The answer is the gate`.
- Handoff text, used verbatim in both flows: `Do not push, open a pull request, or merge from this flow directly`.
- Detached HEAD keeps exactly two options: push as new branch and create a PR, or keep as-is.
- No CI step, CI wait, hook, or autonomous-mode change.

## Review Focus

- **Plan approval read as ship approval.** The gate rule sits directly above the menu, so it is read before any action is taken. Task 2 pins its wording; Task 4's pressure test exercises it.
- **A PR opened before the menu.** Both implementation flows must forbid it in words. Task 3 pins both lines.
- **Quick Reference drifting from the menu again.** The test pins all four rows, not just the menu. Task 1.
- **The detached HEAD path.** The gate rule must not break its reduced two-option menu. Task 1 pins both options.
- **Option 1 pausing after the PR.** The skill must say the menu answer authorizes the whole sequence. Task 1 pins the phrase; Task 2 adds it.

- [ ] **Step 1: Write the failing contract test**

Create `tests/opencode/test-pr-gate.mjs`:

```js
import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const here = path.dirname(fileURLToPath(import.meta.url));
const repo = path.resolve(here, '../..');

const read = (rel) => {
  const file = path.join(repo, rel);
  return fs.existsSync(file) ? fs.readFileSync(file, 'utf8') : null;
};

const FINISH = 'skills/finishing-a-development-branch/SKILL.md';
const EXECUTING = 'skills/executing-plans/SKILL.md';
const FINAL_REVIEW = 'skills/subagent-driven-development/references/final-review.md';
const HANDOFF = 'Do not push, open a pull request, or merge from this flow directly';

const failures = [];
const check = (name, ok, detail = '') => {
  console.log(`${ok ? 'PASS' : 'FAIL'} ${name}${ok || !detail ? '' : `: ${detail}`}`);
  if (!ok) failures.push(name);
};
// Prose wraps across lines; compare it as one line.
const flat = (text) => text.replace(/\s+/g, ' ');

const finish = read(FINISH);
check('finishing skill exists', finish !== null);
if (finish) {
  const prose = flat(finish);
  check('menu offers Ship it first',
    finish.includes('1. Ship it: commit, push, create PR, merge, and clean up'));
  check('menu has no default marker', !finish.includes('(default)'));
  check('gate rule sits before the menu',
    prose.includes('Do not push, open a pull request, or merge before this menu'));
  check('gate names its answer as the authorization',
    prose.includes('The answer is the gate'));
  check('Ship it runs without a second prompt',
    /no further prompt/i.test(prose));
  check('detached HEAD keeps its two options',
    finish.includes('1. Push as new branch and create a Pull Request') &&
    finish.includes("2. Keep as-is (I'll handle it later)"));
  for (const row of [
    '| 1. Ship it | yes | yes | - | yes |',
    '| 2. Merge locally | yes | - | - | yes |',
    '| 3. Create PR | - | yes | yes | - |',
    '| 4. Keep as-is | - | - | yes | - |',
  ]) {
    check(`quick reference row: ${row}`, finish.includes(row));
  }
}

for (const rel of [EXECUTING, FINAL_REVIEW]) {
  const text = read(rel);
  check(`${rel} exists`, text !== null);
  if (!text) continue;
  check(`${rel} forbids a direct PR`, flat(text).includes(HANDOFF));
}

if (failures.length > 0) {
  console.error(`\n${failures.length} check(s) failed`);
  process.exit(1);
}
console.log('\nAll PR gate contract checks passed');
```
